آموزش گام‌به‌گام

شروع سریع

نصب، ویزارد اولیه و اولین ورود به وب‌پنل را قدم‌به‌قدم یاد بگیرید.

در پنل: / مخاطب: مالک، ادمین، نماینده، ادمین پاسارگارد، سلسله‌مراتب

این بخش برای کیست؟

همه نقش‌ها — مخصوصاً کسی که ربات را روی سرور نصب می‌کند یا اولین‌بار وارد وب‌پنل می‌شود. بعد از نصب، مالک معمولاً ویزارد را کامل می‌کند؛ بقیه نقش‌ها بیشتر برای ورود روزانه به همین صفحه مراجعه می‌کنند.

نصب سریع

روی اوبونتو ۲۲٫۰۴ یا جدیدتر:

bash <(curl -fsSL https://raw.githubusercontent.com/Mrclocks/PGClockBot/main/get.sh)

منوی انگلیسی باز می‌شود. گزینهٔ Install را بزنید و صبر کنید تا سرویس بالا بیاید. سپس در مرورگر ویزارد اولیه را کامل کنید.

مثال واقعی

فرض کنید IP سرور شما 203.0.113.10 است:

  1. نصب را تمام کنید.
  2. بروید به http://203.0.113.10:9000/
  3. در ویزارد: یوزر/رمز وب، توکن ربات تلگرام، و اتصال پاسارگارد را پر کنید.
  4. Finish بزنید و با همان یوزر وارد پنل شوید.
  5. پاورقی منو را ببینید: برای حساب ریشه معمولاً برچسب مالک است (نقش نشست همچنان admin).
راهنما

پورت پیش‌فرض وب‌پنل ۹۰۰۰ است. اگر پشت فایروال یا کلود هستید، این پورت باید باز باشد (یا از ریورس‌پراکسی با دامنه استفاده کنید).

اگر پروژه از قبل روی سرور هست

cd PGClockBot
bash get.sh
# یا
bash pgclock.sh

آپدیت: منو → Update. فایل .env و دیتابیس حفظ می‌شوند؛ آپدیت دستی با کپی‌پیست پوشه توصیه نمی‌شود.

ویزارد اولیه چه چیزهایی می‌پرسد؟

معمولاً این‌ها را یک‌بار تنظیم می‌کنید:

موردچرا لازم است؟
یوزر و رمز وبورود به پنل مدیریت
توکن رباتاتصال به تلگرام
آدرس و اعتبار پاسارگاردساخت سرویس VPN بعد از خرید
تنظیمات پایه فروشگاهشروع کار بدون پنل خالی

اگر ویزارد را نیمه‌کاره رها کنید، ممکن است فقط با لینک یک‌بارمصرف یا از خود سرور قابل باز شدن باشد.

اولین کار بعد از نصب

  1. در تنظیمات ربات (/settings) متن خوش‌آمد و دکمه‌های منو را ببینید و در صورت نیاز فارسی‌سازی کنید.
  2. یک پلن بسازید و به تمپلیت/گروه پاسارگارد وصل کنید.
  3. روش پرداخت (مثلاً کارت‌به‌کارت) را در تنظیمات پرداخت پر کنید.
  4. در تلگرام به ربات /start بزنید و یک خرید آزمایشی بگیرید.
  5. رسید آزمایشی را از مدیریت مالی تأیید کنید و ببینید سرویس ساخته می‌شود.
  6. اگر منو محدود به نظر می‌رسد، نقش‌ها را بخوانید — معمولاً دسترسی است نه باگ.

چک سلامت سریع

bash pgclock.sh status
bash pgclock.sh service
curl http://127.0.0.1:9000/health

اگر health جواب ندهد، اول سرویس و پورت را درست کنید؛ بعد سراغ تنظیمات فروشگاه بروید.

خطای رایج

مشکل: صفحهٔ وب باز نمی‌شود یا Timeout می‌دهد.

علت رایج: فایروال پورت ۹۰۰۰ را بسته، یا سرویس بالا نیست.

راه حل:

bash pgclock.sh service
curl http://127.0.0.1:9000/health
sudo ufw allow 9000/tcp
خطای رایج

مشکل: ویزارد می‌گوید فقط با لینک یک‌بارمصرف.

علت رایج: از اینترنت بدون توکن gate باز کرده‌اید.

راه حل: روی سرور bash pgclock.sh status بزنید و لینک کامل را کپی کنید، یا از خود سرور با 127.0.0.1 باز کنید.

نکته

قبل از هر آپدیت بزرگ، از تنظیمات وب پنل بکاپ بگیرید. بکاپ/آپدیت/SSL فقط برای مالک در تب‌های /settings است؛ نقش‌های دیگر برای رمز حساب از /security استفاده می‌کنند.
