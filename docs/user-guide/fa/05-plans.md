# پلن‌ها

## معرفی

Plan مشخص می‌کند چه سرویس یا محصولی با چه قیمت، مدت اعتبار و محدودیت ترافیکی ارائه شود.

## مشخصات

- نام و توضیح
- قیمت
- مدت اعتبار
- Data Limit
- Trial بودن
- فعال/غیرفعال بودن
- ترتیب نمایش
- Template و Groupهای PasarGuard
- الگوی نام کاربری PasarGuard
- سبک دکمه Telegram

## Platform و Reseller Plan

Plan پلتفرم با Plan متعلق به یک Reseller متفاوت است. مالکیت Plan باید در Scope فروشگاه رعایت شود.

## مثال

یک Plan می‌تواند ۳۰ روز اعتبار و ۵۰ گیگ ترافیک داشته باشد. هنگام خرید، Order به Plan متصل می‌شود و پس از تکمیل چرخه تحویل، سرویس مربوطه ساخته یا فعال می‌شود.

## نکات

غیرفعال کردن Plan به معنی حذف سفارش‌ها یا سرویس‌های قبلی نیست؛ بیشتر برای جلوگیری از فروش جدید استفاده می‌شود.
