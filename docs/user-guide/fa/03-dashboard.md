# داشبورد

## این صفحه برای چیست؟

در داشبورد می‌توانید وضعیت کلی سیستم و فروشگاه را سریع ببینید.

## چه چیزهایی را می‌بینم؟

- کاربران
- سفارش‌ها و پرداخت‌ها
- تیکت‌های پشتیبانی
- سرویس‌های نزدیک به انقضا
- وضعیت PasarGuard
- آمار فروش

## آموزش

برای بررسی یک مورد، روی همان بخش از داشبورد کلیک کنید تا وارد صفحه مربوط شوید.

## مثال

اگر یک پرداخت در انتظار بررسی است، روی بخش پرداخت‌ها بزنید و همان پرداخت را بررسی کنید.

## نکته

اگر با حساب Reseller وارد شده‌اید، آمار فقط مربوط به فروشگاه خودتان است.
