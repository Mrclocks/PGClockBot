# CLI و عملیات

CLI برای عملیات نگهداری و عیب‌یابی سیستم استفاده می‌شود.

## دسته‌های اصلی

- Status
- Start / Stop / Restart
- Logs
- Health
- Backup / Restore
- Migration
- Doctor

## Migration

Migration باید با نسخه برنامه و Database Engine هماهنگ باشد.

## Health

Health برای بررسی وضعیت اجزای سیستم است و نتیجه Probe نمایشی را نباید با Authorization اشتباه گرفت.

## Backup

قبل از عملیات مخرب یا Migration، Backup معتبر تهیه کنید.
