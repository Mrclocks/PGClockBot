# متغیرهای پیام

## مفهوم

Message Variable یا Shortcode متغیری است که هنگام ارسال پیام با مقدار واقعی جایگزین می‌شود.

## نمونه‌ها

- `{name}` نام کاربر
- `{order_id}` شناسه سفارش
- `{traffic_remaining}` ترافیک باقی‌مانده
- `{points}` امتیاز Loyalty
- `{wallet_balance}` موجودی Wallet
- `{referral_code}` کد معرفی

## مثال

متن:

`سلام {name}، موجودی شما {wallet_balance} تومان است.`

در زمان ارسال، مقدار واقعی کاربر جایگزین متغیرها می‌شود.

## نکته

نام و دامنه هر متغیر باید مطابق Registry نسخه جاری باشد. استفاده از متغیر ناشناخته نباید با حدس یا تغییر نام انجام شود.
