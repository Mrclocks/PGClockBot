# Update و نگهداری

## قبل از Update

- Backup معتبر بگیرید.
- نسخه فعلی را ثبت کنید.
- Migrationهای مورد انتظار را بررسی کنید.
- وضعیت Database و PasarGuard را بررسی کنید.

## بعد از Update

- Health Check را اجرا کنید.
- Login Web و Bot را بررسی کنید.
- دسترسی نقش‌های حساس را بررسی کنید.
- وضعیت PG را بررسی کنید.
- عملیات اصلی Shop و Order را تست کنید.

## Rollback

Rollback باید بر اساس نسخه و وضعیت Migration انجام شود. بازگرداندن صرفاً فایل برنامه بدون درنظرگرفتن DB می‌تواند سیستم را ناسازگار کند.
