# کاربران

## معرفی

صفحه کاربران برای مشاهده و مدیریت کاربران Bot و اطلاعات مرتبط با سرویس آن‌ها استفاده می‌شود.

## اطلاعات کاربر

اطلاعاتی مانند شناسه Telegram، نام، نقش، موجودی Wallet، امتیاز Loyalty، Referral Code، وضعیت Block و یادداشت مدیریتی می‌تواند در پروفایل کاربر وجود داشته باشد.

## سرویس‌ها

هر کاربر می‌تواند سرویس‌های فعال یا قبلی داشته باشد. سرویس به Plan و در صورت استفاده از PasarGuard به PG User متصل می‌شود.

## عملیات رایج

- جستجو و مشاهده کاربر
- بررسی سرویس‌ها
- بررسی سفارش‌ها
- بررسی وضعیت پرداخت
- بررسی Wallet و Loyalty
- بررسی وضعیت Block
- عملیات مرتبط با سرویس در صورت داشتن مجوز

## Scope

Reseller فقط کاربران فروشگاه خودش را مدیریت می‌کند. Platform Owner نیز در مسیرهای فروشگاهی Platform باید از داده‌های tenant دیگر جدا بماند.

## مثال

اگر کاربر «علی» متعلق به فروشگاه Reseller A باشد، Reseller B نباید بتواند با حدس زدن شناسه کاربر، پروفایل یا Wallet او را مشاهده یا تغییر دهد.

## نکته

شناسه عددی یا Telegram ID به‌تنهایی اثبات مالکیت داده نیست؛ Scope باید در Backend بررسی شود.
