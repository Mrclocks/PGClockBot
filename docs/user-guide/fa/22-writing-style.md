# شیوه نگارش راهنما

- از همان نام‌هایی استفاده شود که کاربر در Web Panel می‌بیند.
- از اصطلاحات برنامه‌نویسی و نام فایل‌ها در متن آموزشی استفاده نشود، مگر در بخش مخصوص فنی.
- هر صفحه با یک توضیح کوتاه شروع شود: «این صفحه برای چیست؟»
- آموزش‌ها کوتاه و مرحله‌ای باشند.
- برای هر دکمه یا گزینه، نام دقیق همان گزینه در پنل نوشته شود.
- مثال‌ها واقعی و ساده باشند.
- از توضیح معماری، کد، API و جزئیات داخلی در راهنمای کاربر پرهیز شود.
- نکات امنیتی فقط زمانی گفته شوند که برای انجام کار کاربر لازم باشند.
- متن‌ها شلوغ نباشند؛ بخش‌های طولانی به چند قسمت کوتاه تقسیم شوند.

## قالب پیشنهادی هر صفحه

### این صفحه برای چیست؟
یک توضیح کوتاه.

### چه کارهایی می‌توانم انجام دهم؟
چند مورد کوتاه.

### آموزش
1. مرحله اول
2. مرحله دوم
3. مرحله سوم

### نکته
فقط نکات ضروری.
