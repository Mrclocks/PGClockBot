# Reseller

## معرفی

Reseller یک نماینده مستقل فروش با Shop و محدوده داده خودش است.

## چرخه Reseller

ایجاد و فعال‌سازی نماینده، اتصال هویت و فروشگاه، تنظیم Plan و دسترسی‌ها و سپس مدیریت کاربران و سفارش‌های همان فروشگاه.

## دسترسی

دسترسی‌های Reseller باید از ACL فروشگاه و در بخش PasarGuard از Role واقعی PG تبعیت کند.

## محدودیت tenant

Reseller A نباید کاربران، سفارش‌ها، Wallet، Loyalty یا Ticketهای Reseller B را ببیند یا تغییر دهد.

## Bot و Web

دسترسی فروشگاهی Web و Bot بر اساس مدل مشترک مجوز فروشگاه طراحی شده، اما مدیریت PasarGuard ادمین اصلی از مسیرهای مخصوص خودش انجام می‌شود.

## مثال

اگر Reseller یک Plan اختصاصی بسازد، آن Plan متعلق به همان Shop است و نباید در کاتالوگ Reseller دیگری ظاهر شود.
