# Setup و نصب

## مراحل کلی

1. آماده‌سازی محیط و تنظیمات.
2. تنظیم Database.
3. تنظیم Bot و Web.
4. تنظیم PasarGuard در صورت استفاده.
5. تکمیل Setup Wizard.
6. ایجاد/بررسی Owner.
7. بررسی SSL و دسترسی Web.
8. اجرای Health Check.

## Setup Gate

فرآیند Setup محدودیت‌های امنیتی دارد و برخی عملیات فقط در شرایط و مسیر مورد انتظار Setup قابل انجام‌اند.

## PasarGuard

بعد از تنظیم credentialها باید دسترسی واقعی حساب بررسی شود؛ Login موفق لزوماً به معنی Owner بودن یا داشتن همه Featureها نیست.

## اولین بررسی

بعد از Setup، ورود Web، Bot، اتصال PG، Database و وضعیت credentialها را بررسی کنید.
