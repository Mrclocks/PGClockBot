# تنظیمات

تنظیمات سیستم چند حوزه دارد و بعضی گزینه‌ها فقط برای نقش‌های مدیریتی مناسب‌اند.

## حوزه‌های اصلی

- Bot و Telegram
- Appearance و نام‌گذاری
- Notifications
- Payment و Finance
- Wallet و PAYG
- Support
- Backup
- SSL
- Update
- PWA
- Links
- Shop

## Bot

تنظیمات مربوط به Bot، منوها، پیام‌ها و رفتارهای Telegram در این بخش مدیریت می‌شوند.

## Notifications

اعلان‌های سفارش، پرداخت، انقضا، مصرف و سایر رویدادها می‌توانند بر اساس تنظیمات سیستم فعال یا غیرفعال شوند.

## SSL

گواهی و کلید خصوصی برای سرویس Web حساس‌اند و نباید در اختیار نقش‌های فروشگاهی قرار گیرند.

## Update

قبل از Update در محیط Production بهتر است Backup معتبر وجود داشته باشد و وضعیت Migration بررسی شود.

## Shop Settings

تنظیمات فروشگاه Reseller نباید باعث دسترسی به تنظیمات Platform یا فروشگاه دیگر شود.
