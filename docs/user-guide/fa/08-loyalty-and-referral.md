# Loyalty و Referral

## Loyalty

سیستم Loyalty برای نگهداری امتیاز، Ledger، Rule، Reward و Tier استفاده می‌شود.

### Points

امتیازها باید از طریق Ledger قابل ردیابی باشند؛ موجودی فعلی به‌تنهایی جای تاریخچه تراکنش را نمی‌گیرد.

### Rules و Rewards

Rule مشخص می‌کند چه رویدادی امتیاز ایجاد کند و Reward مشخص می‌کند کاربر چگونه از مزیت دریافت‌شده استفاده کند.

### Tier

Tier سطح وفاداری کاربر است و می‌تواند با قوانین سیستم به مزایا یا تخفیف‌های متفاوت متصل شود.

## Referral

هر کاربر می‌تواند Referral Code داشته باشد و کاربر جدید از طریق آن به معرف مرتبط شود. رویدادهای Referral می‌توانند باعث ثبت پاداش شوند.

## مثال

کاربر «سارا» کد معرفی خود را برای «مریم» ارسال می‌کند. مریم با آن کد وارد می‌شود و اگر شرایط Rule برقرار باشد، رویداد Referral در Ledger ثبت و پاداش مربوطه اعمال می‌شود.

## امنیت

Referral و Loyalty باید tenant-aware باشند تا یک Reseller نتواند روی کاربران یا امتیازهای فروشگاه دیگر عملیات انجام دهد.
