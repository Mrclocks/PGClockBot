## Panel UI

1. **صفحه ورود** — اتمسفر هم‌سبک صفحات ۴۰۴/۵۰۰ (orb، شبکه، کارت blur) بدون خط accent بالای باکس؛ autofill با submit خودکار
2. **ساعت لودینگ داشبورد** — روی `/home` و `/pg` تا بعد از آماده‌شدن ویجت‌های `/body` محو می‌شود
3. **حذف سرویس** — از ویرایش کاربر وب و ربات (ادمین + کاربر) با تأیید؛ حذف کاربر پاسارگارد رکورد محلی را هم پاک می‌کند
4. **لیست کاربران** — روز/گیگ تغییرمانده در جدول می‌ماند؛ مودال بعد از ذخیره با رفرش دوباره باز نمی‌شود
